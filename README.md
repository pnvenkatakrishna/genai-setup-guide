The goal of this repository is to provide a **structured setup and learning foundation for Generative AI development**.

By completing the repository, you will gradually prepare yourself to:

* ✅ Set up a GenAI development workstation
* ✅ Configure Git and GitHub
* ✅ Configure SSH authentication
* ✅ Prepare AWS for GenAI-related development
* ✅ Prepare Google Cloud for GenAI-related development
* ✅ Configure access to different AI Model Providers
* ✅ Understand how LLM providers fit into GenAI development
* ✅ Prepare an environment for Agentic AI development
* ✅ Work with cloud-based and local development environments
* ✅ Build upon this foundation for RAG, Agents, MCP, LLMOps, and GenAI projects

> 🧠 The objective is not simply to install tools.
> **Understand what you are setting up, why it is required, and how it fits into the GenAI ecosystem.**

# 🔐 Security & Best Practices

GenAI development often involves API keys, cloud credentials, tokens, and other sensitive information.

Treat credentials as **secrets**.

### ❌ Never commit these to GitHub

```text
API Keys
Access Keys
Secret Keys
Passwords
Tokens
Private Keys
Cloud Credentials
.env files containing secrets
```

### ✅ Prefer

```text
Environment Variables
        ↓
.env files locally
        ↓
.gitignore
        ↓
Secret Management
```

Always check your repository before pushing changes.

> 🚨 **If a secret is accidentally pushed to a public repository, consider it compromised and rotate/revoke it immediately.**

# 💡 Tips for Students

* Follow the repository in sequence.
* Complete one setup section before moving to the next.
* Verify every installation after completing a setup.
* Practice commands manually.
* Keep your API keys and credentials secure.
* Never commit secrets to GitHub.
* Use environment variables for sensitive configuration.
* Read official documentation.

* Understand the purpose of every technology.
* Ask **"Why do we need this?"** before asking **"How do I use this?"**

* Keep your GitHub repositories organized.
* Build projects instead of only watching tutorials.
